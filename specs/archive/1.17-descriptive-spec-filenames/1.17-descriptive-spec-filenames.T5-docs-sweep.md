## Goal
The filename form is a user-visible file-format change, so root `CLAUDE.md`'s "Commands,
hooks, and README stay in sync" rule applies: every surface that shows a spec path or
describes the spec model gets updated in lockstep.

- `README.md` — the spec model section: both filename forms + the `flow.spec_filename` knob.
- `docs/guide.md` — 13 spec-path references; update the ones that teach the format, leave
  historical examples alone.
- `docs/how-it-works.md` — the spec-model diagram shows `<id>-<slug>` for both shapes.
- root `CLAUDE.md` — Project Structure's `specs/` line describes the slugged form.
- `hooks/CLAUDE.md` — add `spec-path` to the preflight source-of-truth table; note the
  guard accepts both stems and reads no knob.
