## Goal
Put the judge in the loop at the two authoring seams, gated by the existing autonomy knob rather than a new one.

**`implement.md` §2, pre-sign-off (mandatory).** After the plan/draft detail file is composed and before sign-off or the `auto-build` write, dispatch one `flow:flow-spec-reviewer`. Resolve mode with the existing `flow-preflight.sh autonomy` call already made at the top of the path — no new precedence rules:
- `checkpoint` → **advisory**. Surface the verdict alongside the plan; the human is already paused and makes the call.
- `auto-build` → **blocking on `CONCERNS`**, exactly mirroring the verifier at §3. One bounded revision of the draft addressing the findings, re-review once; if it still returns `CONCERNS`, **escalate** — fall back to `checkpoint` and hand the verdict to the user. This is the missing counterpart to the verifier: today `auto-build` checks the *how* and nothing checks the *what*.

**`add.md`, at the existing confirm step (optional).** The path already shows the draft and confirms before writing. Offer the review there; on decline, write as today. Never make idea capture pay an agent round-trip it didn't ask for.

Findings are advice, not edits — the main thread applies anything that warrants a change, on the user's confirmation, per the standing reviewer rule.
