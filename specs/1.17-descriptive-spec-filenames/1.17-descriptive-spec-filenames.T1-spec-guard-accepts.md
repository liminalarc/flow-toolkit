## Goal
Relax `flow-spec-guard.sh`'s two filename rules so a slug is decoration, not a mismatch:

- **Stem check** (currently `flow-spec-guard.sh:89-93`, a hard block): accept `stem == id`
  or `stem == "<id>-<slug>"` where `<slug>` is non-empty. Anything else still blocks with
  the same actionable message, now naming both legal forms.
- **Task detection** (currently `:121-123`): `stem_prefix` is derived by stripping
  `.T<n>` from the stem; it must also tolerate a `-<ctx>` suffix on the task segment
  (`<id>-<slug>.T2-token-refresh` → prefix `<id>-<slug>`) and still equal the parent dir
  name, so the local-AC nudge fires on slugged task files and never on a flat spec.

Identity comes from front-matter `id:`, never parsed out of the filename — so an id
containing `-` (`BL-12`) is unambiguous. Test-first: `hooks.test.sh` cases before the edit.
